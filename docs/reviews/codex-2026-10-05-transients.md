# Codex review: thermal transients

2026-10-05. Code reviewed: the transient work in commits e2c2a81 to c3f7b8a (validator, writer, run script, results parser, independent finite-volume solution, run manager, server). Two auditors: `silent-failure-hunter` and `specification-gap-auditor`. Ten distinct findings; all confirmed by reading the code and by the probes described; all fixed.

| # | Finding | Fix | Test (and the mutation that fails it) |
|---|---|---|---|
| 1 | **High.** The time-step check compared the half-step solution only at the saved outputs, so with one output (or any sparse output) a pulse that is not resolved looked converged (78.9 K difference at 5 ms against about 1e-8 K at the single output). Both auditors. | The independent solutions record the hottest cell and the extremes at every step; the check compares coarse against fine at every step of the run, and the rise used for its threshold is the largest over every step. | the same case with 1 output and with 20 gives the same, failing, value (outputs-only comparison restored: fails) |
| 2 | **High.** A wall temperature of -1 K passed: the wall value was only checked for presence, and the cross-check compared cells only. | Every wall value must be above 0 K; the cross-check also compares each wall value with the independent solution's boundary relation. | -1 K refused; +5 K on the wall fails the cross-check (each check removed: fails) |
| 3 | **High.** Cell centres only had to be distinct and in the right region: halving every fuel centre in `C` still passed with a "verified" profile at the wrong radii. | Each centre must be where this case's mesh puts it (the volume centroid of the wedge cell, within 0.1% of a cell width). | halved fuel centres refused (check removed: fails) |
| 4 | **High.** Cost: the validator accepted 30000 cells x 100000 steps; the three independent solves (about 5 x that work) would block the server for minutes after the solver's timeout had been cleared. | A budget of cells x steps = 3e6 in the validator (`E_TIME`, with the numbers); the editor preview already skipped above its own limit. | 4.2e6 refused naming the product (budget check removed: fails) |
| 5 | Medium. Extremes used `Math.max(...list)` over all cells and all outputs: 1000 fuel cells x 200 outputs overflowed the stack. | `maxOf` and `minOf` loops everywhere a list can be large. | a 600000-value list works while spreading it throws |
| 6 | Medium. Finite inputs became Infinity on unit conversion (1e308 MJ/m3/K) and then threw in the writer; 5e-324 J/m3/K became `Cp 0`. | `toSI` refuses a value that overflows on conversion (`E_UNITS`); a heat capacity must lie between 1e3 and 1e8 J/m3/K at the stated value or across its range (`E_OUT_OF_RANGE`; catches wrong units such as 3 J/m3/K meant as 3 MJ). | overflow, underflow and wrong-unit cases (bounds removed: fails) |
| 7 | Medium. A linear heat capacity could be negative at the initial temperature if that lay outside its stated range. | The initial temperature must lie inside each linear heat capacity law's range (`E_OUT_OF_RANGE` at `/transient/initialTemperature`). | negative-at-start case (check removed: fails) |
| 8 | Medium. The whole-step tolerance grew with the step count (1e-6 x steps): 99999.09 s with a 1 s step was accepted as 99999 steps. | The tolerance is 1e-9 relative, for the validator, the parser's write times and the manager's completion test. | 100000.05 s / 1 s refused |
| 9 | (part of 1) The all-step extremes also feed the property-range check, so an excursion between outputs counts. | Extremes of the independent solution at every step are combined with the saved outputs. | covered by the out-of-domain pulse test; an excursion visible only between outputs is not separately tested (see below) |
| 10 | (part of 4) Same cost point for the run manager. | Same budget. | as 4 |

New schema vectors: `units-heat-capacity-overflow`, `range-heat-capacity-implausible`, `range-initial-temperature-outside-heat-capacity-range`, `time-too-much-work`. 517 tests pass with the solver on; seven deliberate faults in the new checks each fail a test.

Not covered: no test makes the property-range check fire from an excursion that exists only between two saved outputs (constructing a transient that leaves a range and returns between outputs needs a fast cooling case; the union logic is exercised only through the out-of-domain pulse). The independent solution still runs inside the server process, now bounded to seconds by the budget rather than moved to a worker.
