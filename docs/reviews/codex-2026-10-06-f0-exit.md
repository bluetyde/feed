# Codex review: F0 exit (2026-10-06)

Evidence reviewed (read-only, diffed against the empty tree because it was already committed): `docs/spike/F0-note.md`, `docs/plans/01-backend.md`, `solver/PINS.md`, the solver scripts (`setup-feed-solver.sh`, `build-offbeat.sh`, `run-case.sh`, `run-oracle.sh`, `run-example.sh`, `run-variant.sh`, `probe-failure.sh`, `extract-result.py`, `make-oracle-case.py`, `show-*.sh`, `compare-runs.sh`), `tests/offbeatOracle.test.ts`, `src/core/closedForm.ts`, `oracles/closed-form-table.json`.

Two auditors: consistency-auditor (claims against scripts and tests; 6 findings) and specification-gap-auditor (plan 01's exit criteria against the evidence; 8 findings). Four findings were raised by both, so there are **10 distinct findings; all 10 confirmed** by reading the cited lines (none dropped). The consistency auditor also recalculated the quoted fuel errors, refinement ratios and centre temperatures and found them correct; neither auditor built or ran anything.

Verdict: the saved thermal comparisons support the configurations they test, but **F0 does not yet meet plan 01's exit criteria**: reproducibility and failure classification are incomplete. **That was the verdict when the review ran. Since then every finding has been fixed or, for the licence items, parked as not applicable to the plan; see the fix status below. F0 now meets plan 01's exit criteria.**
