# Teaching cases

Each case carries a `label` (synthetic or sourced), units on every number, and in its `citation`/`description` what is read from where. Sourced cases are checked against the source's own numbers in `tests/`.

| File | What it is |
|---|---|
| `synthetic-pin.json` | Illustrative pin with closed-form answers (the oracle pin). Synthetic. |
| `annular-synthetic-pin.json` | The same with a 1 mm central hole (insulated). Synthetic. |
| `lwr-uo2-burnup.json` | A typical PWR pin at 20 kW/m with UO2 fuel at 40 MWd/kgHM (FRAPCON-3.4's modified NFI conductivity) and Zircaloy cladding (MATPRO's conductivity): the two laws are sourced, everything else is chosen. A frozen-burnup snapshot. Synthetic. |
| `synthetic-pin-hot.json` | The oracle pin with hot dimensions on (free linear expansion from 20 °C, typical coefficients that are not sourced). Synthetic. |
| `ksu-triga-hot-element.json` | K-State TRIGA hottest element, 1.25 MW, prescribed wall temperature; reproduces SAR Table 4.8. Sourced. |
| `ksu-triga-1p25mw-film.json` | The same with the SAR's film coefficient (eq. 7); reproduces eq. 9. The SAR's eq. 7 and Table 4.8 disagree by 8 K; see the case. Sourced. |
| `ut-triga-hot-channel-trace.json`, `ut-triga-hot-channel-annular.json` | UT-Austin hot channel against TRACE's digitized profile (Figure 4.30), solid and with the zirconium rod. Comparison cases, not oracles. Sourced, with values read from a figure. |
| `synthetic-pulse.json` | A 10 ms triangular power pulse (50 kJ/m) on the synthetic pin from a cold start; the fuel interior reaches the adiabatic value E/c. Synthetic. |
| `synthetic-pulse-operating.json` | The same pulse on top of a steady 20 kW/m: the run starts from the pin's steady operating state. Synthetic. |
| `synthetic-pulse-kinetics.json` | A $3 reactivity insertion on the synthetic pin: the power history is GENERATED by six-group point kinetics with fuel-temperature feedback (peak 168 MW, about 11 ms wide, 265 K), not typed in. Synthetic constants except Keepin's textbook delayed-neutron set. |
| `ut-triga-pulse-4p40.json` | A TRIGA $4.40 pulse built from UT-Austin SAR numbers (peak power, 824 C peak, heat capacity law). The SAR gives no power curve; the sech^2 shape is ASSUMED. Illustrative. |
| `ksu-triga-loss-of-pool.json` | The K-State hottest element at 1.25 MW (film case), then a scram and the pool lost at 10 s: the film coefficient falls to 100 W/m2/K, decay heat from an ASSUMED curve; a boundary history. Synthetic, illustrative. |
| `synthetic-coastdown.json` | The synthetic pin at 20 kW/m with a pump trip, a scram and a warming coolant: the film follows an ASSUMED flow^0.8 decay; a boundary history. Synthetic, illustrative. |

The solver is not redistributed with this repository; see the README for the licence and the third-party software note.
